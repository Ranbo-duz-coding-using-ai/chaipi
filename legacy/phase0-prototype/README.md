# Phase 0 prototype (not used)

The first ChAIpi design: a 1.3" OLED HAT, a 5-way joystick and voice input (Vosk), written in Python. It was replaced in revision 2 by the colour-screen OS that the device runs today ([mockup/chaipi-os.html](../../mockup/chaipi-os.html) and [device/](../../device)). This code is kept as a record only. It isn't installed on the device or tested any more.

Its design docs are in [docs/history](../../docs/history/README.md).
