Shell

Change the screen to see the same interface on other displays: it re-lays itself out for the size and shape, including portrait. The power switch cuts power instantly, like the real one, and every move is already saved. The USB-C port charges the battery, and in USB drive mode it also connects to a computer or phone. Click it to plug in a cable.

Transfer, from any phone

  1. On ChAIpi: Settings → Transfer → Activate. The device starts its own Wi-Fi network and a small web page.
  2. On your phone: join the ChAIpi Wi-Fi. Scanning the code on the device's screen joins it for you.
  3. The ChAIpi page opens by itself. Type the 4-digit PIN shown on the device, so nobody nearby can sneak in.
  4. Download games as .txt or a single .zip, copy any game as PGN, and upload engines, Python games, puzzle packs and backups. Everything you send shows up on the device straight away.
  5. Back up: Settings → Transfer → Back up settings → Phone. ChAIpi starts sharing by itself, and after the PIN the phone opens on Download backup.

This phone is live and linked to the simulator above: activate Transfer on the device, then tap through on the phone. Uploads here only read the file's name and size, and downloads are simulated, since this preview page can't save files.

What each button does

Joystick
Moves the cursor one square. Once a piece is picked up, it jumps between legal squares only. Pressing it down works like Confirm.
Confirm
Picks up a piece, then drops it on a legal square. In menus it selects.
Undo (Backspace)
Drops the piece you're holding, or takes back the last move. On the Resume banner it discards the saved game.
Esc
Goes back one screen. Leaving a game asks whether to save it or discard it.
Tab
Switches the side panel: Game → Analysis → System. Hold it for a full-screen view.
Menu
Opens the game menu. Hold it anywhere for the quick panel: theme, vibration, Wi-Fi, brightness.
Fn
Programmable. By default: Hint in Play, Play best move in Helper, Flip board in Two player. Change it in Settings → Controls.
Power switch
Hard on/off. Menu → Shut down is the gentle way.
